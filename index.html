Video-Scanner

Läuft komplett im Browser — kein Node.js, kein Backend. Direkte Videolinks lassen sich immer herunterladen; das Scannen ganzer Webseiten klappt nur, wenn die Zielseite Cross-Origin-Zugriffe erlaubt (browserseitige Sicherheitsgrenze, CORS).

Funktioniert direkt als Datei (Doppelklick) oder gehostet über GitHub Pages.
>
Hinweis: Lade nur Videos herunter, für die du die Rechte besitzt oder deren Lizenz das erlaubt (eigene Inhalte, Creative-Commons-Material o. Ä.). HLS-Streams (.m3u8) werden erkannt, aber nicht zu einer einzelnen Datei zusammengeführt.
